3. DESCRIPTION OF AI USE
------------------------------------------------------------
I declare that AI tools were used in the development of this assignment in the following capacity:

**Claude (Anthropic)** was used as a development assistant throughout the project. Specifically, it was used to generate the initial Flutter implementation of `lib/main.dart`, produce the `pubspec.yaml` configuration and the `AndroidManifest.xml` permission set, and draft the `README.txt` documentation.

It was also used to reason about the architecture before any code was written. The approach adopted was to make SQLite the single source of truth, and to model a visit as one database row that moves through queued -> pending -> done/failed, so that the offline queue (Requirement 8) and the WorkManager job poller (Requirement 10) are served by one mechanism rather than two separate ones.

After the provided API reference was consulted, the networking layer was revised against the documented contract: handling the third `failed` job state so a rejected visit is not polled indefinitely, making the `create_landmark` image optional with the server's 2MB and jpeg/png/webp limits enforced before upload, sending `delete_landmark` and `restore_landmark` as form-urlencoded bodies carrying only `id`, and respecting the `is_active` flag returned by `get_landmarks`.

All AI-generated code was reviewed, understood, and verified by me before inclusion in the submission. I take full responsibility for the final submitted work and am able to explain every part of the codebase.

This declaration is made in the interest of academic transparency and in accordance with BRAC University's guidelines on the ethical use of AI tools in academic work.
